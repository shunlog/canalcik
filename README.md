## Requirements

- **Platform**: hosted website for a single user
    - needs to introduce data from mobile phone easily
    - needs desktop to view the Word docs, move them to usb and print them

- View docs and excel sheets

- Upload document templates (using the templating language)
    - Upload updated template
- Create docs by filling in forms
- Every edit is auto-saved
- Incomplete forms are shown as "drafts"

- Generate document from form:
    - Save generated document version,
    so that when the template is updated, the older generated versions are still available

Generated documents:
- *Comanda materiale*
- *Act constatare defectiune*

Data sources:
- *Categorii produse*
    - Categorie (hierarchic, 5 levels)
    - Denumire produs
    - Cod produs (based on category)
- *Gestiune flota*
    - Nr. inmatriculare
    - Nr. inventar 
    - Denumire configuratie
    - Sofer (1 or more)
